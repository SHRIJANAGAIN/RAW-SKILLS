# SKILLS-NON-T1

Skills and skill files that are **not tier-1** - incomplete, truncated or otherwise
unusable as-is. They are kept here for reference only and are **not** listed in
[SKILLS.md](../SKILLS.md) or loaded by any agent.

| File | Why it is here |
| --- | --- |
| `reasoning/master-reasoning/SKILL.md` | Fenced code block never closes - file is cut off |
| `reasoning/reasoning-planning-decision-making/SKILL.md` | Fenced code block never closes - file is cut off |

Rules for this folder:

- Do not symlink or copy these into `.agents/skills/`, `.claude/skills/` and similar.
- If a file here gets completed upstream, move it back into `skills/<letter>/<name>/`
  and delete the copy here in the same commit.
- Anything added here should be listed in the table above with the reason.
